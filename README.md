<h1 align="center">Converz</h1>
<p align="center">กดปุ่มค้าง · ลากไฟล์ · ปล่อยลงบนนามสกุล — เสร็จ<br>
โปรแกรมแปลงไฟล์ รูป / วิดีโอ / เสียง สำหรับ Windows · ฟรี · ทำงานในเครื่อง ไม่อัปโหลดไฟล์ไปไหน</p>

## ดาวน์โหลด

ไปที่หน้า **[Releases](../../releases/latest)** แล้วโหลด **Converz-Setup-x.x.x.exe** มาติดตั้ง

> ถ้า Windows ขึ้นหน้าจอ “Windows protected your PC” ให้กด **More info → Run anyway**
> (ขึ้นเพราะโปรแกรมไม่ได้ซื้อใบรับรองจาก Microsoft ไม่ใช่ไวรัส)

## วิธีใช้

1. กดปุ่ม **Ctrl** ค้างไว้ แล้วลากไฟล์ (จะเป็นไฟล์บนเดสก์ท็อปหรือในโฟลเดอร์ไหนก็ได้)
2. จะมีวงโดนัทรายชื่อนามสกุลไฟล์โผล่ขึ้นมาตรงเมาส์
3. ปล่อยไฟล์ลงบนนามสกุลที่ต้องการ
4. ไฟล์ใหม่จะไปอยู่ข้างไฟล์เดิม และมีแจ้งเตือนเล็กๆ ที่มุมขวาล่าง กดที่แจ้งเตือนเพื่อดูไฟล์ได้เลย

ถ้าไม่อยากเปลี่ยนไฟล์แล้ว ให้ปล่อยไฟล์ตรง**กลางวง** หรือลากออกไปนอกวง

**รวมหลายรูปเป็น PDF:** ลากเมาส์คลุมรูปที่ต้องการ → กด Ctrl ค้าง → ลากรูปทั้งหมด → ปล่อยที่ **PDF**
หน้าใน PDF จะเรียงตามชื่อไฟล์ (IMG_2 มาก่อน IMG_10)

**วิธีอื่น:** คลิกขวาที่ไฟล์ → **ส่งไปยัง (Send to)** → **Converz** หรือเปิดหน้าต่างโปรแกรมแล้วลากไฟล์มาวาง

## แปลงอะไรได้บ้าง

| ลากไฟล์ประเภท | เลือกได้ |
|---|---|
| **รูป** (JPG, PNG, HEIC จาก iPhone, WEBP, AVIF, BMP, TIFF, GIF, ICO) | JPG · PNG · PDF (รวมหลายรูปได้) · WEBP · บีบไฟล์ · ย่อครึ่ง · ICO · BMP · TIFF |
| **วิดีโอ** (MP4, MOV, MKV, AVI, WEBM, WMV, FLV, 3GP …) | MP4 · MP3 (ดึงเสียงออก) · บีบไฟล์ · GIF · ปิดเสียง · MOV · MKV · WEBM · AVI |
| **ไฟล์เสียง** (MP3, WAV, M4A, AAC, FLAC, OGG, OPUS, WMA …) | MP3 · WAV · M4A · บีบไฟล์ · FLAC · OGG · AAC |

- ตัวเลือกที่ใช้บ่อยจะขยับขึ้นไปอยู่ด้านบนของวงเอง
- ไฟล์ต้นฉบับไม่ถูกแก้หรือลบเด็ดขาด ถ้าชื่อซ้ำจะเติม (1), (2) ให้
- ลากหลายไฟล์พร้อมกันได้

## เลือกปุ่มลัด และปุ่มไหนชนกับคำสั่งอะไรของ Windows

ตั้งค่าได้ในหน้าต่างโปรแกรม (กดไอคอน Converz ที่มุมขวาล่างของจอ)

| ปุ่ม | ปกติ Windows ใช้ปุ่มนี้ + ลาก เพื่อ… | ถ้าเผลอไปปล่อยในโฟลเดอร์อื่นแทนวงโดนัท |
|---|---|---|
| **Ctrl** (แนะนำ) | คัดลอกไฟล์ | ได้สำเนาเพิ่มมา 1 ไฟล์ ไม่มีอะไรเสียหาย |
| **Alt** | สร้างทางลัด (shortcut) | ได้ไฟล์ทางลัดเพิ่มมา 1 ไฟล์ ไม่มีอะไรเสียหาย |
| **Shift** | ย้ายไฟล์ | ไฟล์จะถูกย้ายไปอยู่ที่นั่น ⚠️ ต้องระวังกว่า |

ถ้าปล่อยลงบนวงโดนัท Converz จะ**ไม่ย้ายและไม่ลบ**ไฟล์ต้นฉบับ ไม่ว่าจะเลือกปุ่มไหน

## ตั้งค่าอื่นๆ

- **คุณภาพ:** ไฟล์เล็ก / สมดุล / ชัดที่สุด
- **เก็บไฟล์ใหม่ไว้ที่:** ข้างไฟล์เดิม หรือโฟลเดอร์ที่เลือกเอง
- **เปิดพร้อม Windows** และ **เมนูคลิกขวา (Send to)** เปิด/ปิดได้
- **หยุดชั่วคราว:** คลิกขวาที่ไอคอนมุมขวาล่าง → หยุดชั่วคราว

## สำหรับคนดูแลโปรเจกต์

### สร้างไฟล์ .exe ใหม่
ทุกครั้งที่อัปโค้ดขึ้นสาขา `main` GitHub จะสร้างโปรแกรมให้เองบนเครื่อง Windows (ดูได้ที่แท็บ **Actions**)
ทดสอบว่าแปลงไฟล์ได้จริง แล้วเอาไฟล์ติดตั้งไปวางที่หน้า **Releases** ให้อัตโนมัติ

ถ้าจะออกเวอร์ชันใหม่ ให้แก้เลข `VERSION` ในไฟล์ `converz/__init__.py` ก่อนอัป

### รันจากโค้ดบนเครื่องตัวเอง (ไม่จำเป็น)
```
pip install -r requirements.txt
python -m converz
```
ต้องมี `ffmpeg.exe` อยู่ใน PATH หรือในโฟลเดอร์ `build_ffmpeg/` ด้วย

### โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `converz/converter.py` | ตัวแปลงไฟล์ (Pillow สำหรับรูป/PDF, ffmpeg สำหรับวิดีโอ/เสียง) |
| `converz/formats.py` | รายการนามสกุลและตัวเลือกในวงโดนัท |
| `converz/ui/donut.py` | วงโดนัท |
| `converz/app.py` | ไอคอนมุมจอ, ตัวจับปุ่มค้าง+ลาก, คิวงาน |
| `.github/workflows/build.yml` | สูตรให้ GitHub สร้าง .exe |
